# Requirements Summary

## Functional requirements

- Virtual environment with configurable camera and beacon
- One or more moving targets
- Pan/tilt camera control loop
- Automatic detection and tracking
- Closed-loop control with prediction
- Disturbance injection framework
- Scenario runner and metrics export
- Offline local execution

## Non-functional requirements

- Deterministic simulation behavior when seeded
- Modular design with clean interfaces
- Lightweight and free/open-source stack
- Quick local demonstration
